# LocalClarity

> LocalClarity is an AI-driven local search management platform for enterprises, agencies and
> global brands. It manages Google Business Profiles, tracks local rankings and keywords,
> monitors and responds to reviews across 50+ sources, and manages listing data across Google,
> Apple, Bing, Facebook and Waze. Its REST API exposes six operations over profiles,
> organizations, locations, reviews, replies and Google performance insights.

Generated by API Evangelist on 2026-08-13. LocalClarity does not serve an llms.txt of its own:
https://www.localclarity.com/llms.txt returned 404 and https://dev.localclarity.com/llms.txt
returned the site's single-page-app HTML shell.

## How the API works

- Authentication: an API key sent in the `Authorization` request header. An administrator
  generates it at Reporting -> Data Studio -> API in the LocalClarity app. The full key is
  shown once; revocation is immediate and irreversible; per-key request audit logs are kept
  for 12 months.
- Entry point: `getProfiles`. It is the only operation that takes no identifier, and the
  `profileId` it returns is mandatory on every other call.
- Five of the six operations are POST, including four reads. They are therefore not cacheable
  and not safe by HTTP semantics.
- There is no idempotency key, no pagination, no request-id header and no versioning scheme.
- Quota exhaustion returns HTTP 403 with `{"error":"Quota exceeded"}` - not 429 - and no
  Retry-After header, so a client cannot compute a backoff from the response.
- Missing or revoked keys return HTTP 401 with `{"message":"Unauthorized : ..."}`.

## Operations

- getProfiles (GET /api/getProfiles): List the profiles this key can reach.
- getOrganizations (POST /api/getOrganizations): List the accounts inside a profile.
- getLocations (POST /api/getLocations): List business locations for a profile, optionally
  narrowed to one account. Returns the Google Business Profile location resource.
- getReviews (POST /api/getReviews): Retrieve reviews for a profile, optionally narrowed to
  one location.
- sendReply (POST /api/sendReply): Publish a reply to one review on Google or Facebook. This
  is the only write operation and it has no idempotency contract.
- getInsights (POST /api/getInsights): Retrieve Google Business Profile performance metrics.

## Known gaps

- No OpenAPI, AsyncAPI, webhooks or event surface.
- No MCP server and no A2A agent card; /.well-known/ serves nothing on any host.
- No SDK in any package registry; the github.com/localclarity org has zero public repos.
- No published rate-limit thresholds or response headers.
- No security.txt, vulnerability-disclosure policy, trust center or named certification.
- The base URL the provider's own documentation declares,
  https://localclarity.cloud.tyk.io, returned NXDOMAIN on 2026-08-13.
